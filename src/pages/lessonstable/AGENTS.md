# 一、按维度的测试用例

## A. 跨周测试

1. 在"本周"视图下，通过前进/后退箭头逐周切换 1→20 周，验证课程展示随周数正确增减（尤其单双周课程在相邻两周之间应交替出现/消失）
2. 直接用周选择器跳跃式选周（如从第 3 周跳到第 16 周），验证无残留上一周数据
3. 点击"返回本周"按钮，验证周数/学期数精确回到本周/本学期
4. 周次为 19、20 时验证 UI 表现（显示"放假中"文案）
5. 点击同一天同节次的多门冲突课程，验证冲突时间展示：
    - 完全重叠周次（交集=全集）
    - 部分重叠（如 1-8 周 与 5-16 周，交集应为 5-8）
    - 单双周与普通周次混合冲突（交集应正确过滤奇偶）
    - 理论不重叠但被判定冲突的课程，交集显示"无"

## B. 跨学期测试

1. 用学期选择器切换到"上/下/短"三种学期类型，尤其短学期
2. 切换到有课数据的历史学期（当前学年往前 3 年内）与尚无数据的"下一学年"（当前学年往后 1 年），验证空态展示

## C. 寒暑假测试

1. 服务端返回的周次为 0 或负数（寒暑假期间"距开学还有 N 周"）时：
    - 页面应能正常兜底负数周次，不崩溃，显示"放假中"
2. 基础信息尚未返回时打开课表页（P0，弱网/冷启动叠加暑假期间最易复现）：
    - 模拟接口延迟 3~5 秒后立即进入课表页
    - 验证是否出现异常周次或异常学年选项

## D. 跨学期切换的确切边界

1. 服务端学期/周次数据更新的当天（新学期教务系统开放日），验证：
   - 小程序冷启动后，课表页是否正确取到新学期数据
   - 小程序保持后台跨过边界（不重启，仅前后台切换）后，课表页是否停留在旧学期
2. 自然周边界（周日 23:59 停留在 App 内 vs 周一 00:01 重新打开），验证当前周次是否正确更新为新一周（取决于基础信息是否被重新拉取）

## E. 弱网 / 异常网络测试

1. 完全断网打开课表页：验证是否展示上次缓存的课表数据（缓存有效期 1 天），同时是否有"网络异常"提示
2. 弱网/超时（限速至 2G/弱 3G 或模拟 12 秒以上超时）：
    - 验证请求是否自动重试两次后才报错
    - 验证学期切换过程中弱网时 UI 停留在旧数据而非白屏/崩溃
3. 切换学期瞬间断网：学期选择已变但数据未更新时页面不崩溃，最终展示错误提示或旧缓存（周次切换是纯前端过滤，不发请求，无此风险）
4. 首页速览卡片与课表主页共享缓存的跨页验证：先在弱网下进首页的课表卡片加载失败，再进课表主页，确认二者共享同一份缓存（表现为课表主页秒开旧数据或同样失败）
5. 实践课程入口在弱网下的表现：主请求未完成/失败时，"查看实践课程"按钮应保持隐藏，而不是显示但点击后空白

## F. 新功能/重构专项回归

1. 实践课程弹窗：字段展示正确，空数据兜底不崩溃
2. 教室地点解析：覆盖真实教室数据中的各种楼名+房间号格式，尤其低版本微信环境

# 二、时间排期：什么时间点测哪些点

结合校历节奏与撰写日期（2026-07-03，暑假中）：

```
现在（暑假中，周次为 0 或负数）
  └─ 立即可测：C 组全部用例
    这是"放假中"UI、空周边界最容易复现的窗口，不要等到开学后

开学前 1~2 周（教务系统学期数据已切换，但用户端可能仍持旧缓存）
  └─ 重点测：D 组「跨学期切换边界」
     - 验证冷启动后能正确识别新学期
     - 验证缓存（有效期 1 天）是否导致"开学当天仍显示上学期旧数据"
     - 配合 E 组做一次弱网+切学期边界的组合测试

开学第 1 周（周次=1）
  └─ 重点测：A 组用例 1、3（前进后退、返回本周）
     - 周选择器下边界（第 1 周不可再往前）是否生效
     - 首页速览卡片与课表主页数据是否一致（新学期数据量小，易于人工核对）

学期中期，任选一次真实跨周边界（如周日夜间→周一凌晨）
  └─ 重点测：D 组用例 2（自然周边界滚动行为）
     - 需真实保持小程序后台运行跨越该时间点，非模拟数据可替代
     - 同时验证 A 组用例 5（课程冲突周次交集）在真实课表数据上的表现

学期尾声（第 17~20 周）
  └─ 重点测：A 组用例 4
     - 这是全学期唯一能自然复现"边界周"的窗口，务必不要跳过

短学期窗口（通常紧邻暑假开始前后）
  └─ 重点测：B 组用例 1（短学期专项）
     - 短学期周数规则可能与常规学期不同，需与教务数据核对周选择器的 20 周上限是否够用
```

弱网测试（E 组）：不依赖校历，随时可测，但应叠加在以上每个阶段的关键操作节点执行——
- 开学前后的学期切换操作（与 D 组同时进行）
- 暑假期间的冷启动进入课表页
- 任意时间的"点击刷新按钮""点击课程弹窗"操作，验证局部请求失败不影响已渲染内容。
